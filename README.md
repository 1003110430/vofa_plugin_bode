# VOFA+ 伯德图插件

版本：0.15.0。适用：Windows x64 / VOFA+ 1.3.10。

选择输入、输出通道，绘制幅值、相位和相干性；支持缩放、独立窗口、曲线降噪、关键参数标注及传递函数辨识。

## 安装

1. 下载并完整解压本目录的 `VOFA-Bode-0.15.0-Windows-x64.zip`。
2. 保存需要保留的VOFA缓冲数据，关闭VOFA。
3. 默认安装目录的用户，右键 `安装或更新插件.cmd`，选择“以管理员身份运行”。
4. 如果VOFA安装在其他位置，将包内 `plugins/widgets/bode` 整个文件夹复制到实际VOFA安装目录的 `plugins/widgets/` 下。
5. 重启VOFA，在控件列表找到 `bode` 并拖入画布。

使用插件不需要安装Python、MATLAB或Node.js。其他电脑同样解压、安装即可。

## 使用

1. 在VOFA中正常选择通信协议和接口，采集同步的输入、输出数据。
2. 在插件选择输入X和输出Y，填写实际上传数据的采样率。
3. 暂停接收，用VOFA底部选择条选取数据，点击“读取并计算”。改变时域选区后需要重新计算。
4. 用鼠标滚轮缩放、拖动平移、单击查看数值，Auto恢复自动量程。下方频率条可单独调整横轴。
5. “图上参数”选择要显示的参数；“曲线降噪”可开关并选择强度；“传递函数辨识”用于拟合模型。

**注意采样率：控制环频率不一定等于上传数据频率。例如控制环20kHz、每两个周期上传一次，应填10000Hz，VOFA的Δt对应0.1ms。**

显示降噪不改变原始定量分析。输入必须有有效激励；噪声大、相干性低或分辨率不足时，参数和辨识结果需谨慎判断。−3dB截止点相对于低频参考增益，不一定对应绝对−3dB。

## 自动 / 手动显示频段

图下方“显示频段”可切换“自动选择”和“手动设置”。手动模式填写起始、终止Hz后点击“应用”或按回车，直接改变三图横轴，无需重新读取数据，也不改变纵轴或已辨识模型。

0或留空表示FFT边界。起始必须小于终止，并在当前FFT支持范围内；填写错误时保留原图并显示提示。拖动频率条或交互改变横轴会切入手动模式；点击“横轴Auto”恢复自动选择。收起参数设置后这组控件仍可见。

## 自带Demo测试

安装包内已包含 `Demo数据/third_order.csv`，是20kHz采样、输入频段0.25～2000Hz的三阶系统人工数据。

在VOFA选择FireWater引擎和“Demo数据”接口，勾选CSV数据源并选择解压后的 **Demo数据文件夹**。收到80000点后停止接收；Δt设0.05ms，插件Fs设20000Hz，输入I0、输出I1，再读取计算。

理论低频增益约6.02dB，相对低频−3dB截止约90.09Hz。完整加载步骤和理论参数见安装包中的 `Demo使用说明.txt`。CSV发送周期是整批回放间隔，不是采样间隔。
